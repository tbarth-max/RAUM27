## AXIOM 0, "Ableitung 1" — not haltbar as written, not closed off

Not a verdict that the underlying idea is dead. As written, this specific
claim doesn't follow from the stated definition — kept open as a branch
to revisit (maybe ratio/product got swapped, maybe a different X- was
intended), not declared impossible.

The claimed derivation is:

    X- := 1/X+  (reciprocal definition, as AXIOM 0 itself states)
    therefore |X+|/|X-| = 1, "verified in practice for X+=8,6,5,7,999 -- always exactly 1"

Checked directly:

    X+=8:   X-=1/8,   |X+|/|X-| = 64        (not 1)
    X+=999: X-=1/999, |X+|/|X-| = 998001    (not 1)

Given X- = 1/X+, the ratio |X+|/|X-| equals |X+|/(1/|X+|) = |X+|**2, not 1
-- exactly where the entry's own proof trails off ("= |X+|^2 * ..."). What
*is* true by construction from AXIOM 0 is the **product**, X+ * X- = 1
(already stated correctly in AXIOM 0 itself, and reproduced below). The
"practical verification, always exactly 1" for the *ratio* could not have
run against the reciprocal definition as written; either a different
X- was used without updating the definition, or the check wasn't run.

```python
from fractions import Fraction as F

def check_ableitung_1(x_plus):
    """Puts the claim as written next to what the definition actually gives."""
    x_plus = F(x_plus)
    x_minus = 1 / x_plus  # AXIOM 0's stated reciprocal definition
    ratio = abs(x_plus) / abs(x_minus)      # the claim as written: not 1 in general
    product = x_plus * x_minus              # what AXIOM 0 actually guarantees: always 1
    return ratio, product

for x in (8, 6, 5, 7, 999):
    ratio, product = check_ableitung_1(x)
    assert product == 1
    assert ratio == F(x) ** 2  # the ratio is X+^2, not 1, whenever |X+| != 1
```

Kept in the historical entry as-is; noted here rather than silently
fixed in place, since the point of the note-taking process is that the
mistake stays visible, not that it quietly disappears.

## Two smaller inconsistencies

- **KETTE C's own header** says "VIER unabhängige Herleitungen," while
  its body already reduces derivations 3+4 to one. Of the resulting
  three, only one (`C=4/3` from corners/faces, in `cube_symmetry`) has
  code behind it in this repo; the sector derivation and the "Lean proof
  at n=1" remain unverified here pending their source.
- **KETTE E** treats "reaching ~300 million" as a meaningful target for
  both the base-9 and decimal counting schemes, without carrying forward
  the correction already in this repo
  (`test_speed_of_light_threshold_is_not_unit_invariant`): 300 million is
  specifically `c` in **m/s**; the same physical speed is a completely
  different number in any other unit. Landing near that number is not
  evidence of anything structural about either counting scheme.

## One framing note, not an error

KETTE B calls B1 (1/2, 1/4, 1/8 across dimensions 1D/2D/3D) and B2
((1/2)^n across n repetitions of a fixed 2D construction) "two
independent confirmations of the same sequence... strong indication of
real structural anchoring." The index `n` means something different in
each (dimension count vs. repetition count); both landing on powers of
1/2 is close to guaranteed by each construction individually (B1 halves
each of 3 independent dimensions; B2 halves area on a shape whose
diagonal is already tied to sqrt(2)), not a coincidence needing a shared
explanation. Worth keeping the derivations, not the "strong indication
of anchoring" framing.
