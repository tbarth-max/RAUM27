# data/

`lotto_6aus49_since_2000.csv` — real German Lotto 6-aus-49 draw results,
2000-01-01 through 2026-07-22 (2724 draws). Columns: `date,n1,n2,n3,n4,n5,n6,superzahl`.

Source: [daowa89/lottery-archive](https://github.com/daowa89/lottery-archive),
an automated public archive of official lottery draw results. Used here
as the real-data test case for `raum27.lotto_benchmark` — see the main
README for what that benchmark does and does not establish.
